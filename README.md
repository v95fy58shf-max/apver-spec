# Apver

Apver, derived from **APVerse**, is a personal Agent world foundation.

It is a local-first foundation for turning a person's intent into reusable workflows while keeping memory transparent, portable, and document-based. Agents, models, and runtimes are replaceable; workflows are independent modules that can be installed, distributed, and eventually traded.

This repository is the public concept record for Apver. It intentionally contains no main application code and makes no decision about a future software license or commercial licensing model.
