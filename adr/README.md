# Architecture Decision Records

ADRs document significant implementation choices made after the Apver concept specification.

ADRs do not replace or downgrade Apver's original core principles. `ORIGIN.md`, `VISION.md`, and `ARCHITECTURE.md`, together with their public Git history, remain the primary historical sources. A core concept or protocol change must use the RFC process before an implementation ADR records the resulting decision.

Copy `0000-template.md`, assign the next available number, and record the context, decision, consequences, alternatives, and references. Do not create a fictional accepted ADR.
