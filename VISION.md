# Vision

Apver aims to become a personal foundation on which people can build their own Agent world.

For ordinary users, the primary interface is intent: describe what should be done. Apver should then plan a workflow, generate one, or install an existing workflow. The underlying Agent, model, and runtime remain replaceable.

Memory should stay understandable and portable through layered documents. Workflows should be reusable independent modules rather than capabilities locked inside a single platform.

Over time, a community may create, distribute, install, and trade workflows through a marketplace, while local-first operation keeps personal computing from depending strongly on platform-owned cloud infrastructure.
