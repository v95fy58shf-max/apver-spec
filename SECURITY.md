# Security Policy

This repository currently contains primarily concept specifications, documentation, templates, and repository automation. The Apver main implementation is not published here.

## Reporting a Security Issue

Use the repository's private GitHub Security Advisory reporting flow when available. If private reporting is unavailable, contact the repository owner through an appropriate private GitHub channel before public disclosure. No dedicated security email address is currently declared.

Do not submit credentials, API keys, tokens, private keys, personal data, exploit details, or other sensitive material in a public Issue, Discussion, or pull request. Public Issues may be used for non-sensitive documentation errors and general hardening suggestions.
