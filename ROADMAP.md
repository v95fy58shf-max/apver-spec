# Roadmap

This high-level roadmap contains no delivery dates and does not imply that unpublished capabilities are implemented.

## Phase 0 — Concept Specification

Maintain a clear, traceable specification of Apver's origin, principles, terminology, and conceptual architecture.

## Phase 1 — PPM Capability Alignment

Define how relevant PPM capabilities and boundaries align with the Apver concept.

## Phase 2 — Apver Core Baseline

Define and validate the minimum foundation for intent, memory, workflows, and replaceable execution components.

## Phase 3 — Modular Workflow Runtime

Define a runtime model for installing, composing, executing, and observing independent workflow modules.

## Phase 4 — Community Workflow Ecosystem

Establish contribution and compatibility foundations for community-developed workflow modules.

## Phase 5 — Marketplace Infrastructure

Define infrastructure and protocols that could support discoverable and freely traded workflow modules without pre-deciding a commercial licensing model.
